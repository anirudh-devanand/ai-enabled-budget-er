# AI Enabled Budget-er

Personal finance platform with live institution sync, agent-assisted categorization, rich visualizations, and an AI budget planner.

**Status:** research complete — implementation not started.

## Docs

- [Market research](docs/market-research.md) — competitors, bank-app table stakes, enrichment APIs, security baseline

## Planned differentiators

1. Perfect categorization — no vague merchant or alphanumeric descriptors in the UI
2. Visualization of every relevant metric (net worth, cash flow, Sankey, recurring, forecasts)
3. AI assistant grounded in real user data via tool-calling
4. AI budget planner that prescribes concrete changes from income/spending vs goals
5. Best table-stakes features from Monarch, YNAB, Copilot, Rocket Money, and Cleo

## Stack (intended)

Plaid for aggregation/enrichment; mobile (iOS + Android) + web; production backend. Exact choices TBD in ADRs as the build starts.
